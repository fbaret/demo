# Démos Prodélien

Pages de démonstration publiques des preuves de concept du projet (dépôt de travail privé : `fbaret/prodelien`). Données fictives, sauf `carte-hautes-pyrenees/` : données réelles et ouvertes (Agence Bio, Licence Ouverte 2.0 ; OpenStreetMap, ODbL), publiées avec l'accord du porteur du 27/10/2026, sans téléphone ni nom de gérant. Aucun secret ne doit être poussé ici.

- `carte-hautes-pyrenees/` : données réelles des Hautes-Pyrénées, fond Plan IGN gris, source `poc-donnees/` du dépôt de travail.
- `carte-france/` : France entière, 300 000 producteurs fictifs, fond Plan IGN gris, données découpées par zone (`data/`), source `poc-carte/france/`.
- `carte-ign/` : carte sur fond Plan IGN (MapLibre GL JS), source `poc-carte/ign.html`.
- `carte/` : carte sur fond communal simplifié (d3), source `poc-carte/index.html` + `data.js`.

Publication : GitHub Pages, branche `main`, dossier racine.
